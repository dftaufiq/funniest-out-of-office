One line, at most 140 characters, of the funniest out-of-office auto-reply — written deterministically to `/output/entry.txt` for make.fun's "The Funniest Out-of-Office" bounty.

## Run it

```sh
python3 main.py
```

Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (default `/output`).
